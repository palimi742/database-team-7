# Point of Sale (POS) - COSC 3380 Databases

## Team 7: Grocery Store System

### Frontend Setup
    1. cd into frontend folder
    2. Install dependencies (npm install)
    3. Start dev server (npm run dev)

### Backend Setup
    1. cd into backend folder
    2. Install dependencies (npm install)
    3. Create a .env file in backend with DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME, and PORT=3000 
        password is the only one wrapped in a string
    5. Test database connection (node scripts/test-db.js)
    6. Start backend (npm start)
